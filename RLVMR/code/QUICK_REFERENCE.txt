┌─ 🔍 最有用的命令 ──────────────────────────────────────────────────────────┐
│                                                                              │
│  # 实时监控任务（最常用）                                                    │
│  python debug_ray_toolkit.py monitor --interval 5                           │
│    → 显示所有任务状态                                                        │
│    → 自动检测长时间运行的任务（>30秒）                                       │
│    → 每5秒刷新一次                                                           │
│                                                                              │
│  # 查看集群状态                                                              │
│  python debug_ray_toolkit.py status                                         │
│    → 显示可用资源（CPU/GPU/内存）                                            │
│    → 显示所有节点信息                                                        │
│                                                                              │
│  # 列出所有任务                                                              │
│  python debug_ray_toolkit.py list-tasks                                     │
│  python debug_ray_toolkit.py list-tasks --state RUNNING                     │
│    → 查看任务ID、名称、状态                                                  │
│                                                                              │
│  # 精确定位卡住位置（最强大）                                                │
│  ps aux | grep TaskRunner              # 找到 PID                           │
│  py-spy dump --pid <PID>                # 查看堆栈                           │
│  py-spy top --pid <PID>                 # 实时监控                           │
│    → 精确显示卡在哪一行代码                                                  │
│                                                                              │
│  # 测试环境创建（针对你的问题）                                              │
│  python debug_env_hang.py --timeout 30                                      │
│    → 测试 ALFWorld 导入、配置、环境创建                                      │
│    → 超时会给出诊断建议                                                      │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ ✅ 推荐的调试流程 ────────────────────────────────────────────────────────┐
│                                                                              │
│  第1步: 启动监控                                                             │
│    python debug_ray_toolkit.py monitor --interval 5                         │
│    → 观察是否有任务长时间运行                                                │
│                                                                              │
│  第2步: 如果发现卡住的任务                                                   │
│    ps aux | grep TaskRunner                                                 │
│    py-spy dump --pid <PID>                                                  │
│    → 查看精确的代码位置                                                      │
│                                                                              │
│  第3步: 根据堆栈输出诊断                                                     │
│    - 卡在环境创建 → python debug_env_hang.py                                │
│    - 卡在文件 I/O → 检查磁盘速度/权限                                        │
│    - 卡在网络请求 → 检查网络连接                                             │
│                                                                              │
│  第4步: 尝试修复并重新运行                                                   │

┌─ 💡 小贴士 ────────────────────────────────────────────────────────────────┐
│                                                                              │
│  • py-spy 可以在不停止进程的情况下查看堆栈                                   │
│  • 监控工具会自动检测超过30秒的任务                                          │
│  • Ray Dashboard 提供最全面的信息                                            │
│  • 如果卡住，先用 py-spy 定位，再决定如何修复                                │
