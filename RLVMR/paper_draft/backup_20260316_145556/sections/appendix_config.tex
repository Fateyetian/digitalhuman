\paragraph{SFT data collection.}
Expert trajectories for the SFT cold-start were collected using a rule-based planner
with hindsight relabelling: trajectories are replayed forward from a near-goal state,
and the belief annotations are added post-hoc by a deterministic belief extractor
that reads the ground-truth game state.
This avoids distributional mismatch between the belief format expected during RL
and the beliefs seen during SFT.
